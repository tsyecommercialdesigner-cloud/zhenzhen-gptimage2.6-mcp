# 本地配置

将项目根目录 `.env.example` 复制为 `.env`，设置 `ZHENZHEN_GPTIMAGEGEN_API_KEY`。
默认只读取配置目录内 `.env`；指定其他文件时须提供绝对路径，不搜索父目录。
按 `.env`、进程环境变量、Windows 用户级环境变量的顺序读取；只有文件或目标字段
缺失时才回退到下一来源。目标字段为空、空白、重复或含控制字符，以及文件不可读、
编码或语法错误时，会报配置错误，不回退；环境变量已定义但为空或无效时同样失败。
如果此前通过空 `.env` 字段使用环境变量，请填写有效密钥或移除该字段后重启服务。
入口未指定 `--config-dir` 时目前使用启动工作目录；Host 应显式指定项目绝对路径，
避免从 Host 工作目录读取错误文件。`--env-file` 覆盖路径必须为绝对路径。
进程环境不会被修改，密钥不应提交、写入日志或任务数据。
环境变量在非 Windows 系统仅使用进程级来源。

开发版本新增 `ZHENZHEN_GPTIMAGEGEN_EXPORT_ROOT`：仅在用户决定允许导出时设置为服务器可访问的本机绝对目录，例如 `D:/MCP-host-tests/zhenzhen-gptimage2.6`。可写入配置目录的 `.env` 或进程环境变量；Windows 用户级环境变量可作回退。未设置时导出关闭；空值、相对路径和 `..` 会报错。更改后需停止共享后台及接入进程并重启。三个 Host 共享数据目录时需使用一致的配置。该能力尚未发布及完成 Desktop 验收。

共享后台版本要求使用同一数据目录的接入进程具有兼容的配置目录、凭据、资源限制与软件版本；变更凭据后先停止旧后台并重新启动。诊断和安全停止命令见 [MANUAL](../MANUAL.md#5-启动排障升级与回滚)。此能力尚待发布版及 Desktop 验收。

Chat Completions 的图片尺寸由供应商决定，不能指定宽高。Chat 请求中不应提供
`width` 或 `height`；保存结果的宽高以实际图片为准。需要指定尺寸时使用
Generations 或 Flux 格式。
