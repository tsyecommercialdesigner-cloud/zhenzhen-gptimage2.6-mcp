# 本地结果恢复

启动时，已开始发送但没有完整可验证响应的任务标为 `unknown`，不会自动重新生成。
若完整响应已安全保存，任务转为 `recovery_pending`；调用 `recover_task` 仅重试本地
解析、下载与落盘，不增加生成尝试次数。任务结果中的文件被移动或损坏时，查询报告
不可用，不会重新下载或触发生成。

对 `unknown` 或无法恢复的 `recovery_pending` 可调用 `close_task`，明确提供期望
状态和结案原因；结案释放队列名额，但不表示远程操作已取消。若需要重新生成，
使用新的幂等键。请勿手动删除任务数据库或恢复材料。

当前服务组件需要与 MCP 生命周期和同一个任务锁集合接入后才能作为完整功能使用。
