# 本地数据目录

`reference-staging/` 保存已经验证并冻结的参考图副本，SQLite 的
`reference_assets.local_path` 指向相应文件。`responses/` 保存按任务 ID 与
尝试编号命名的完整响应正文及校验清单。缺失清单或校验失败的正文不能用于恢复。

接收任务前检查剩余空间：至少保留 2 GiB，并加上已有未完成任务预计占用的
文件预算。清理未引用参考图时，调用者必须持有与准备及数据库接收相同的锁，
并提供数据库中全部已引用路径和仍在准备中的路径；不满足这些条件时不要清理。
已经关联的快照和恢复材料不得作为普通缓存删除。

开发版本可将已完成任务中确认不再用于恢复、且未被其他任务共享的参考快照和响应材料
纳入明确授权的清理计划；未完成、待恢复、归属不明和校验失败的材料继续保留。
清理账本保存在 SQLite，计划、结果和用户工作区导出副本的边界见 [MANUAL](../MANUAL.md#8-功能说明)。

共享后台版本由唯一后台进程独占同一数据目录的 SQLite 与调度，多个 stdio 接入进程可共享它；不同数据目录仍相互隔离。`.shared-backend/` 包含受当前用户权限保护的本地发现信息，包含敏感令牌，不应分享或提交。不要通过删除锁文件解除活动进程的占用。此功能在当前工作树中实现，发布和 Desktop 验收状态见 [MANUAL](../MANUAL.md)。
