# 本地数据目录

`reference-staging/` 保存已经验证并冻结的参考图副本，SQLite 的
`reference_assets.local_path` 指向相应文件。`responses/` 保存按任务 ID 与
尝试编号命名的完整响应正文及校验清单。缺失清单或校验失败的正文不能用于恢复。

接收任务前检查剩余空间：至少保留 2 GiB，并加上已有未完成任务预计占用的
文件预算。清理未引用参考图时，调用者必须持有与准备及数据库接收相同的锁，
并提供数据库中全部已引用路径和仍在准备中的路径；不满足这些条件时不要清理。
已经关联的快照和恢复材料不得作为普通缓存删除。

本文件描述存储基础组件；任务接收、数据库关联和启动恢复由后续模块集成。
