# Spec Delta

## ADDED Requirements

### Requirement: 文本结果兼容
系统 SHALL 在 MCP 工具文本内容中提供与结构化结果一致的可解析结果信息，包括适用的任务状态、原件路径和错误；同时保留结构化结果、错误标识与受限图片预览内容块。

#### Scenario: Host 只读取文本
- **WHEN** Host 向模型传递工具的文本内容但不传递结构化内容
- **THEN** 模型可从文本读取任务状态及可用的原件路径，不将预览副本误认为原件

#### Scenario: 查询失败
- **WHEN** 工具返回错误
- **THEN** 文本包含对应错误信息且 MCP 错误标识保持正确，不泄露密钥或原始供应商响应
