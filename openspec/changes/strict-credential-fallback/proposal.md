# Proposal

## Why

当前凭据加载把空值当作缺失并回退，可能意外使用其他来源的旧密钥。用户决定改为仅缺失才回退，配置错误必须明确失败。

## What Changes

- 保留项目文件、进程环境、Windows 用户级环境的来源顺序，仅在字段未定义时查下一个来源。
- 已定义但为空、非法或重复的凭据以及不可读或无法解析的文件直接失败，不输出密钥。
- 更新配置文档、凭据规范和隔离测试；此变更不改变密钥变量名或 Host 工作目录默认定位方式。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `image-generation`: 严格处理凭据来源和配置错误。

## Impact

影响配置加载和启动、配置说明和测试；已经存在空 `.env` 字段并依赖环境变量的用户需要填写密钥或移除该字段。
