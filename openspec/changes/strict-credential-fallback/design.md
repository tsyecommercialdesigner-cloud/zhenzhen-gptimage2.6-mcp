# Design

## Context

见 [proposal](proposal.md)。当前代码通过真值判断选择非空来源，`.env` 重复字段后值覆盖前值。配置目录和绝对覆盖文件由现有入口提供，本变更仅针对已确认的 B 来源和错误规则。

## Goals / Non-Goals

**Goals:** 区分缺失和无效，阻止使用低优先级旧密钥，保留现有优先级和保密边界。

**Non-Goals:** 不改变密钥变量名、服务或 Host 配置；不推断供应商密钥固定前缀；不改变默认 config-dir 的定位。

## Decisions

### ADR-001：严格来源解析

- 状态：已接受。
- 决策：`.env` 文件缺失或目标字段缺失才检查进程环境；进程字段缺失才检查 Windows 用户级字段。目标字段重复、无值、空白、非字符串或包含控制字符时报错；文件语法或读取失败时报错。错误不包含值。
- 原因：明确配置错误，防止错误账户的旧密钥被静默选中。
- 备选：继续按非空值回退；用户选择 B，不采用。
- 兼容：成员需填写空模板字段，或移除字段以使用环境变量；不删除任何文件或用户变量。

## Risks / Trade-offs

- [已有空配置依赖环境变量] → 更新文档与清晰无秘密错误；用户可移除空字段。
- [配置目录默认为调用方 cwd] → 本次只实现 B；与先前接受的安装目录定位习惯的差异作为后续独立工作明确披露，不假称已完成。

## Migration Plan

验证文件和两级环境优先级、错误与脱敏，更新规范及配置文档；如需回滚代码，先确认用户清楚旧版本会对空值回退。
