# Spec Delta

## Purpose

使 Agent 能将 MCP 管理的已生成图像原件安全地复制到用户指定的本地工作区，保留原始内容并提供可核验的结果。

## ADDED Requirements

### Requirement: 原件导出
系统 SHALL 支持以任务 ID 和图片索引将已登记的可用原件导出至授权目标目录，返回目标路径、格式、字节数及摘要，不触发生成或改变原件。

#### Scenario: 导出 GIF 或 SVG
- **WHEN** 用户请求导出已保存的 GIF 或 SVG
- **THEN** 目标文件字节与原件一致，动画或矢量内容保持不变

#### Scenario: 目标已存在
- **WHEN** 目标文件已存在
- **THEN** 不覆盖文件并报告冲突，除非另有明确且受支持的用户授权

### Requirement: 授权路径与可靠复制
系统 SHALL 限制源文件为已登记产物，目标位于用户授权的本机目录，拒绝路径逃逸及不安全的链接或重解析点，并在复制不完整时不报告成功。

#### Scenario: 沙箱路径不可映射
- **WHEN** Host 所提供的工作区路径无法可靠映射为服务端本机路径
- **THEN** 返回明确错误和配置指引，不猜测或写入其他位置

#### Scenario: 原件缺失
- **WHEN** 已登记的原件不存在或摘要不匹配
- **THEN** 拒绝导出并报告原因，不重新生成
