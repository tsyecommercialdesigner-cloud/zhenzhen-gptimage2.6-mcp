# Spec Delta

## MODIFIED Requirements

### Requirement: 日志和生命周期
系统 SHALL 保持 stdout 为 MCP 协议流，脱敏记录诊断信息；接入进程关闭不关闭仍被使用或有未完成任务的共享后台。后台关闭时停止接收并给予在途任务最多 30 秒且不超过剩余期限的宽限期，超时后不再启动请求，必要的状态持久化和资源关闭可以继续完成；不自动删除用户图片。

#### Scenario: 生成中关闭
- **WHEN** 后台接到关闭请求
- **THEN** 停止接收和启动重试，保留未完成任务的恢复状态

#### Scenario: 客户端关闭
- **WHEN** 一个接入进程关闭且其他客户端或未完成任务仍存在
- **THEN** 后台继续运行，已有任务可由其他接入查询，图片和恢复材料保持可用
