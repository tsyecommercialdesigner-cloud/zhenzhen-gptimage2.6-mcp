# Proposal

## Why

一次基础 Flare 静态图请求期望 800×1024，实际返回 796×1024。已保存图片因尺寸不符未登记，恢复时又被报告为参数错误。任务结案后，现有工具无法取回这张本地图片。

## What Changes

- 让发现结果、能力查询与指南共同说明本地输入限制、路由、供应商实测范围及未知提交策略，并提供可直接使用的示例。
- 区分调用参数错误、提交结果未知及响应后处理失败。尺寸不符时返回请求尺寸、实际尺寸和已保存的产物信息。
- 有效静态图尺寸不符时原样登记为成功，通过 SIZE_MISMATCH 提醒 Agent，并返回请求尺寸和实际尺寸。
- 支持按已结案任务找回现有本地原件，保留原结案状态、记录及幂等信息。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `mcp-tool-contracts`：明确参数、能力证据、错误、状态及后续动作。
- `image-results`：将有效静态图尺寸不符作为非阻塞提醒，保留真实像素及原始字节。
- `task-recovery`：澄清恢复条件与结案后果，增加本地原件找回。

## Impact

影响 MCP Schema、能力与恢复资源、生成结果处理、SQLite 恢复元数据、导出校验、手册和 Host 验收。沿用既有生成接口、自动重试条件和幂等规则。范围限于契约及本地结果处理，供应商路由、异步覆盖及图像缩放不在本次变更范围内。
