# Spec Delta

## ADDED Requirements

### Requirement: 可解释的能力与恢复决策
系统 SHALL 在工具发现结果、能力查询和指南中保持一致的约束与示例。能力证据 SHALL 区分本地接受、当前已开放和供应商实测，实测注明适用组合及证据范围。恢复类工具 SHALL 公开参数、前置条件、副作用和结果示例。

#### Scenario: 精确尺寸与档位
- **WHEN** Agent 查看静态图与 GIF 或 SVG 的尺寸约束
- **THEN** 明确 16 倍数规则的本地适用范围，说明 1024 长边仍是基础档、超过 1024 才进入 2k，并说明请求尺寸与供应商实际输出可能不同

#### Scenario: 提交结果未知
- **WHEN** 返回 SUBMISSION_UNKNOWN
- **THEN** 指引保留原任务和幂等键，查询同一任务，说明可能已受理和产生费用，以及未经用户授权不得另行提交

#### Scenario: 参数与后处理错误
- **WHEN** 参数有效但恢复失败
- **THEN** 返回脱敏的后处理原因、可采取的操作和任务标识，不报告 INVALID_ARGUMENT；参数非法时仍准确指出可公开的字段及修正方法

#### Scenario: 用户查看可用动作
- **WHEN** 已保存的静态图尺寸不符，或者任务可显式结案
- **THEN** 静态图通过 SIZE_MISMATCH 报告实际尺寸，提示可正常使用原件；对结案等操作，明确用户确认和后果
