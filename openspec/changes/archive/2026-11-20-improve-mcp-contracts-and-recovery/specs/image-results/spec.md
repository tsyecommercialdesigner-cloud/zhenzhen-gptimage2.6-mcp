# Spec Delta

## MODIFIED Requirements

### Requirement: 完整结果落盘
系统 SHALL 验证图片集合后再标记成功，登记实际尺寸、媒体类型、字节数、路径及摘要；静态 Generations/Flux 尺寸不符且完整结果通过其他校验时，原样登记并报告非阻塞 SIZE_MISMATCH 提醒，Chat 不作请求尺寸比较；GIF 按用户选择的尺寸策略处理。

#### Scenario: 部分下载失败
- **WHEN** 多张图片中一张下载失败
- **THEN** 不标记整任务成功，保留恢复材料且不重新生成

#### Scenario: 格式与请求不符
- **WHEN** 请求 SVG 或 GIF 但供应商返回其他格式或不符合动画要求的文件
- **THEN** 不标记成功，保留恢复证据且不重新生成

#### Scenario: GIF 精确尺寸不符
- **WHEN** GIF 实际尺寸与精确请求不同且使用默认严格策略
- **THEN** 原样保存并报告原件和实际尺寸，任务进入 recovery_pending，不缩放或重新生成

#### Scenario: 用户接受 GIF 实际尺寸
- **WHEN** 用户明确接受已验证的尺寸不符 GIF，或提交时明确选择接受实际尺寸策略
- **THEN** 保存实际尺寸及警告并标记成功，不触发新的生成请求

#### Scenario: 静态图精确尺寸不符
- **WHEN** 静态结果集合完整、格式有效且实际尺寸与请求不符
- **THEN** 原样登记为成功，返回非阻塞 SIZE_MISMATCH 及请求和每张图片的实际尺寸，正常提供预览与导出，不要求确认、不缩放或重新生成

#### Scenario: 批次中个别静态任务尺寸不符
- **WHEN** 批次含通过校验但尺寸不符的静态图
- **THEN** 按成功计数，给出逐项尺寸及提醒，其他子任务各自报告状态

#### Scenario: 已暂存的静态图候选
- **WHEN** 恢复先前开发版已暂存的完整尺寸不符候选
- **THEN** 重验已有文件，完整性通过时直接登记并提示实际尺寸；损坏或缺失时报告恢复问题并保留原记录
