# mcp-tool-contracts Specification

## Purpose

让 MCP 客户端与 Agent 能发现工具用途、正确构造参数、理解约束及安全处理错误和结果，并保留现有业务契约。

## Requirements

### Requirement: 工具参数可发现
系统 SHALL 在 MCP 工具发现结果中为所有公开工具和输入字段提供用途、类型、必填性、默认值及适用约束；生成、查询和导出工具 SHALL 包含可直接构造参数的示例或明确指向可被客户端读取的示例资源。

#### Scenario: Agent 查询单张生成工具
- **WHEN** 客户端发现 `generate_image`
- **THEN** 描述明确 `request` 嵌套结构、必填键、提示词或模板二选一、尺寸和系列选择，并提供有效例子

### Requirement: 条件规则与运行时一致
系统 SHALL 将现有可用的跨字段规则表达在兼容的输入 Schema 或工具说明中，并在服务端执行；描述、Schema 和实际校验不得相互矛盾或拒绝既有合法请求。

#### Scenario: 参考图格式不支持
- **WHEN** Agent 查阅参考图参数
- **THEN** 说明本地路径、PNG 限制、数量限制以及不支持参考图的通道与格式

#### Scenario: 异步与格式限制
- **WHEN** Agent 查阅执行模式及 SVG/GIF 参数
- **THEN** 明确当前实现开放的组合、尺寸和图生图限制，不将供应商实测结果误述为服务已开放的能力

### Requirement: 可操作且脱敏的参数错误
系统 SHALL 对可识别的参数校验错误报告字段路径、约束原因和修正建议；不回显用户输入值、路径、凭据、提示词或内部堆栈，并保持错误编码与原有任务安全语义。

#### Scenario: 互斥字段同时提供
- **WHEN** 请求同时提供提示词与模板代号
- **THEN** 参数错误指出相关字段只能选择一个，不回显提示词内容且不提交生成

#### Scenario: 畸形参数或未知字段
- **WHEN** 输入类型不符或包含未知字段
- **THEN** 错误明确指出安全的字段位置和修正方向，既不泄露原值也不触发远程请求

### Requirement: 安全调用与结果指引
系统 SHALL 说明幂等键复用与冲突、同步和异步返回、查询、原件导出、未知结果和恢复流程，避免将结果不明误判为可安全重新生成。

#### Scenario: 提交结果不明
- **WHEN** Agent 收到结果未知或连接中断
- **THEN** 指引使用原任务 ID 或幂等键查询，不自动使用新键重新提交

### Requirement: 实际 Host 传参验收
系统 SHALL 分别在 Codex Desktop、Claude Desktop Cowork 和 DeepSeek Harness Desktop 实际会话验收 Agent 基于 MCP 契约构造参数，记录安装版本、配置目录、工具参数及结果；调用前核实对应 Host 已应用配置。

#### Scenario: 无收费验证
- **WHEN** 使用受控替身或既有任务进行验收
- **THEN** 验证有效与无效参数、纠错及查询导出，并明确该结果不证明真实供应商生成能力

#### Scenario: 真实生成需授权
- **WHEN** 验收需要提交可能收费的生成请求
- **THEN** 先取得用户对次数及范围的明确授权，结果不明时不盲目重复提交
