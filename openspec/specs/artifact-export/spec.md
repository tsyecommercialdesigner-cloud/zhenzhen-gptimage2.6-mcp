# artifact-export Specification

## Purpose

使 Agent 能将 MCP 管理的已生成图像原件安全地复制到用户指定的本地工作区，保留原始内容并提供可核验的结果。

## Requirements

### Requirement: 原件导出
系统 SHALL 支持以任务 ID 和图片索引将已登记的可用原件导出至用户指定的服务器本机绝对路径，返回目标路径、格式、字节数及摘要，不触发生成或改变原件。

#### Scenario: 导出 GIF 或 SVG
- **WHEN** 用户请求导出已保存的 GIF 或 SVG
- **THEN** 目标文件字节与原件一致，动画或矢量内容保持不变

#### Scenario: 目标已存在
- **WHEN** 目标文件已存在
- **THEN** 不覆盖文件并报告冲突，除非另有明确且受支持的用户授权

### Requirement: 授权路径与可靠复制
系统 SHALL 限制源文件为已登记产物，允许用户选择本机目标目录，无须预设导出根目录；拒绝含父目录跳转及不安全的链接或重解析点，并在复制不完整时不报告成功。

#### Scenario: 自选目标目录
- **WHEN** 用户指定服务器可访问的本机绝对目标路径
- **THEN** 无论是否配置导出根目录，系统均可将原件导出至该路径，已有文件不覆盖

#### Scenario: 沙箱路径不可映射
- **WHEN** Host 所提供的工作区路径无法可靠映射为服务端本机路径
- **THEN** 返回明确错误和配置指引，不猜测或写入其他位置

#### Scenario: 原件缺失
- **WHEN** 已登记的原件不存在或摘要不匹配
- **THEN** 拒绝导出并报告原因，不重新生成
